# 회원 전체 refresh 행 수 기대값 정정

core HTTP15 종료 뒤 첫 DB 확인에서는 단일 세션 로그아웃 후 refresh0행이었다. 이후 별도 Admin probe를 여러 차례 로그인했고 첫 Admin 실행은 로그아웃을 하지 않았다. 따라서 마지막 Admin 세션만 로그아웃한 뒤 회원의 전체 refresh 행 수0을 기대한 검사는1행으로 실패했다. 이 실패는 `db-effects-admin-multiple-sessions.json`에 보존한다.

새 검사는 로그아웃 직전·직후의 DB 행 수 차이를 확인하여 현재 세션 정확히1개 제거를 요구한다. 이전 별도 테스트의 refresh1행은 서버 종료·전용 DB 삭제 시 함께 폐기된다. 기대 범위를 바꾼 이유는 여러 세션이 있는 fixture에 단일 세션 가정을 적용한 검증 오류이며, 서버 로그아웃의 계약을 바꾼 것이 아니다.
