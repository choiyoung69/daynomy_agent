# 손상 저장 데이터 보존 기대값 수정

첫 독립 regression은 KB의 기존 웹 수명에서 가져온 손상 데이터 삭제를 기대했다. 조정자가 새 RN 클라이언트에서 손상 저장 원본 자동 삭제는 데이터 손실 위험이 있어 삭제하지 않고 오류를 표시하도록 명시적으로 구현자에게 요청했다. 구현자가 전한 조정자 10:20 메시지: “storage load corrupt 저장 삭제는 데이터 손실 위험이라 삭제하지 않고 throw로 보존하도록 변경해 주세요.”

따라서 새 독립 regression의 기대값을 저장 원문 보존 및 오류 표시로 바꾸고 첫 실행 로그는 `regressions-initial.log`에 보존했다. 이 변경은 수정한 동시 add/clear race 두 건과 무관하며 고정 core27 테스트를 변경하지 않았다.
