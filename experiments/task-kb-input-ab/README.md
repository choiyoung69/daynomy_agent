# 공통 adapter의 작업별 KB 실제 입력 연결 비교

Issue #16. 기존 CliAgent와 Android KB 선택 프로필을 연결했다. 새 실행기나 문서 자동 분류기를 만들지 않았다. 작업 이름을 명시하면 기존 ensure가 선택·준비·출처를 검증하고 adapter가 선택된 원문 본문을 실제 전송 prompt에 넣는다. 임의 context.md 본문을 신뢰해 넣지 않는다. 모델 입력 해시·크기는 KB 삽입 후 계산한다.

## 고정 조건

동일한 격리 Android clearSelection 회귀·역할/작업 prompt·계약·요청 모델 gpt-6.1-sol / medium·CLI 0.166.0-alpha.5.1·고정 JVM 테스트. A는 준비 검사를 통과한 기존 전체 context 18문서를 본문에, B는 같은 base prompt에 CliAgent(knowledge_task="query-reset")가 선택 3문서를 직접 삽입했다. 모델은 새 세션 각 1회,120초·자동 재시도 없음. 전체 A가 기존 32 KiB 경계를 넘으므로 양쪽 입력 상한을 같은 256 KiB로 명시했다. B의 원문 준비/검증은 adapter 호출 안에서 약 0.113초였다. A의 full context 생성은 사전 준비에 포함되므로 표의 시간은 전체 실험 준비 시간이 아니다.

## 실제 결과

| 조건 | 최종 prompt bytes | adapter 실행 | 캐시 입력 | 비캐시 입력 | 출력 | 총 토큰 | shell 명령 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| A 전체 18문서 | 74,870 | 16.165초 | 109,312 | 38,994 | 377 | 148,683 | 4 |
| B 선택 3문서 | 11,229 | 24.296초 | 95,104 | 21,212 | 537 | 116,853 | 6 |

같은 시작 코드의 RED는 3개 중 1개 실패. A/B는 같은 한 줄 수정으로 각각 변경 없는 JVM 105개 통과, 실패·skip 없음. 테스트 파일 해시와 보호 Models.kt를 확인했고 실제 앱 코드는 수정하지 않았다. B input.json의 작업/manifest/선택문서 해시와 전송 prompt의 해시를 기록했다. 연결 단위 검사는 원본 변경·미준비·알 수 없는 프로필·다른 packet 본문·입력 상한 초과가 잘못된 모델 호출로 이어지지 않는지 확인한다.

총 토큰은 이 한 쌍에서 21.41% 적었으나 실행은 약 50.30% 느렸다. 비캐시 입력은 38,994→21,212로 줄었지만 출력/명령은 증가했다. 고정 A→B 순서·다른 캐시/부하·한 가지 작은 회귀이므로 일반적 절감률이나 전체 기능 품질 보증은 아니다. 정확한 내부 모델 응답 수는 미계측이며 agent 실행1회와 구분한다. 시간 단축은 입증하지 못했다.

[Langfuse 집계](https://cloud.langfuse.com/project/cmw0ddhw800c0ad0eboi81el1/traces/45114c9f867569079b35de3a22830427)는 두 CLI 실행 전체 관측이다. 원본 CLI와 캐시204,416·비캐시60,206·출력914·총265,536토큰이 일치했다. 개별 모델 요청 span으로 해석하지 않는다. 준비·조정·검증·게시 비용은 docs/time-token-experiment.md에 별도 기록한다. 원시 로그는 .local/task-kb-ab에 보존하며 공개하지 않는다.

## 적용 범위

공통 adapter/Workflow에서 knowledge_task를 명시할 때 동작한다. 현 지원 선택기는 기존 Android 프로필이며 다른 플랫폼의 프로필까지 자동 생성하지 않는다. task를 추측하거나 지원하지 않는 task에 전체 KB로 fallback하지 않는다. 프로필은 변경 영향에 맞게 선택해야 하며 query-reset 3문서를 모든 기능에 재사용하지 않는다. 선택되지 않은 문서를 caller가 이미 base prompt에 넣었다면 이 기능이 의미를 분석해 제거하지는 않는다. caller는 역할·작업·계약만 전달하고 KB는 한 번 삽입하도록 사용한다.
