명세, KB, 역할 설정, 실험 코드와 기존 실행 증거를 현재 상태로 보존한다.

## 확인 범위와 제한

Git 상태·원격 메타데이터·추가할 파일 목록을 읽고 파일 크기와 주요 비밀키 패턴을 확인했다.
이는 모든 민감 정보에 대한 완전한 감사를 의미하지 않는다.
앱·서버·DB·하네스·모델 호출·빌드·테스트는 이 기준선 작업에서 실행하지 않았다.
과거 실행 기록은 당시의 증거이며 이번 기준선의 전체 기능 통과를 뜻하지 않는다.
문서의 과거 상태 설명, 플랫폼별 미검증 항목과 기존 실패는 그대로 보존한다.
