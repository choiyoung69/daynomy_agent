# Android 네이티브 첫 파일럿

범위는 Kotlin/Compose의 종목 검색 → 선택 → 최근 저장 종가 표시 → 수동 단가 초안이다.
전체 앱, 인증, 거래 저장, 환율, 운영 배포는 포함하지 않는다. 실행법은
[Android README](../clients/android/README.md)를 따른다. 원본은 수정하지 않았다.

## 결과와 근거

- [최종 실행](../experiments/android-native/evidence/verification-05.json): JVM52개,
  실제 Kotlin/HTTP/Rust/합성 PostgreSQL7개, API33 에뮬레이터 화면5개 모두 성공.
  APK 빌드와 Lint 성공(오류0, 경고9).
- [실제 기기 화면 → Rust/DB](../experiments/android-native/evidence/device-rust-03.json):
  검색·종가 날짜·정밀 소수 가격·수동 입력 자동 채움4조건 성공.
- [구현 리뷰](../experiments/android-native/evidence/review-final.json): 한정된 파일럿 승인.
  코드 작성자와 리뷰어는 분리했지만 리뷰어가 테스트도 작성했으므로 테스트 기대값 자체를
  별도 독립 인증한 것으로 세지 않는다. 리뷰는 현재 소스·APK·XML·로그 해시를 대조했다.
- 테스트를 빈 구현에서 실행해 최초20개 API/49개 JVM 실패를 보존한 후 구현했다.
  7개 백엔드 테스트와 리뷰 회귀3개는 구현 이후 보강했다. 기기 테스트는 구현 전 작성했지만
  red 단계에서 실행하지 않았으므로 모든64개를 최초 구현 전 실행했다고 표현하지 않는다.

## 시간과 지연

중앙 측정 시작은 2026-10-28 17:05:15 KST, 최종 리뷰 종료는18:00:37 KST다.
약55분22초이며 이전 대화 시간, 이후 보고·정리 시간은 이 구간에 포함하지 않는다.
실제 서버와 연결된 네이티브 화면 probe는17:56:23 KST에 성공했다.
첫 환경 준비 완료까지 약11분43초, 최초 통합 구현 수용은17:34:22,
최종 합동 검사 수용은17:51:29였다. 환경 작업과 명세 작성은 겹쳤으므로 합산하지 않는다.
verify.backend/device의 ledger 시간은 이미 함께 실행한 검사 결과의 등록 시간이다.
API 초안의 에이전트 보고 구간은 검색36초·가격25초, 겹친 시간17초였지만
이것은 검증 완료 시간이 아니다. 일부 작성 구간은 시작 기록이 없어 소요 시간을 모른다.

초기 외부 검색2회는 Android 도구 호환성 확인이었다. 이후 구현·리뷰는 로컬 KB와 원본을 사용했다.
주요 추가 작업은 첫 Gradle/SDK/기기 환경, 상태·전송 공통 코드, KB 수용 검사와 증거 기록 도구,
반복 빌드·리뷰 수정이었다. 기능 개발과 실험 도구 구축을 함께 진행해 속도 목표에 비해 범위를 넓혔다.
비교용 순차 실행이 없어 병렬 배속을 주장하지 않는다. 전체 앱30분 완료 가능성도 입증하지 못했다.

## 지식베이스 사용

검색3문서·가격4문서·통합5문서를 로컬 패킷으로 제공한다. 입력 생성과 결과 수용에서
필수 문서·작업·출처·해시·규칙 적용 맵을 확인한다. 관련 검사11개와 기존 지식 검사19개가 통과했다.
검색/가격 초안은 이 검사를 도입하기 전에 작성돼 사후 대조했으며, 통합은 구현 전에 패킷을 받았다.
기계적으로 확인하는 것은 입력 제공·출처 일치·적용 선언이다. 모델의 이해 자체를 증명하지 않는다.

다음 묶음은 기존 프로젝트·전송·상태·테스트 도구를 재사용한다. 새 실험용 프레임워크를 더 만들지 않고
로컬 KB → 필요한 원본 → 해소되지 않는 공백만 외부 확인 순서로 진행한다. 기능별 계약과 핵심 테스트를
준비되는 대로 넘겨 병렬 구현하고, 변경 부분 검사 후 통합 빌드·주요 흐름 검사를 수행한다.
30분 실험 시 구현된 기능, 실제 검증한 기능, 남은 기능을 분리해 기록한다.

## 실패와 수정

앱 OkHttp 직접 의존성 누락, 기기 테스트의 잘못된 import, network-security includeSubdomains 누락을
수정했다. import 수정은 기대값을 바꾸지 않은 별도 기준v2로 보존했다.
리뷰에서 선택 해제 시 검색어 소실, KB 필수 집합/작업 결합 누락, 잘못된 JSON 숫자 허용을 발견했다.
회귀3개 중 수정 전2개 실패·가격 문법 대조1개 성공을 보존하고 수정 후 전체 검사를 통과했다.
직접 기기 probe는 APK 자동 제거와 키보드에 가린 결과 때문에 앞선2회 실패했다.
검사 도구에서 검증 APK 재설치·키보드 닫기를 반영한 별도3차 결과만 성공으로 기록한다.

## 한계

API33 ARM64 에뮬레이터1개만 검증했다. 실제 OS 프로세스 종료 복원, 실기기/다른 OS,
TalkBack·큰 글자·IME 전체 수동 인수는 남았다. release API 주소가 미구성이므로 로컬 debug 파일럿이다.
기존 백엔드/운영 데이터는 수정하지 않았고 실험의 합성 DB·자체 서버·전용 에뮬레이터만 정리한다.
작업 큐 Python은 기록·선행 조건·수용 검사를 담당하며 앱 서브에이전트 실행은 root가 배정했다.
