# React Native 이식 범위

2026-10-28 요청: 기존 독립 테스트 작성→구현→독립 검증 방식, 20분 제한.
원본과 기존 네이티브 기능 지도를 따르며 핵심 사용자 기능을 먼저 연결한다.

| 영역 | 구현 | 검증 경계 |
| --- | --- | --- |
| 종목 | 국내/미국 검색·STOCK/ETF 필터·종가·수동 단가·환율 | 고정 코어 계약 + UI + 실제 Rust HTTP를 구분 |
| 게스트 원장 | 매수/매도·수정/삭제·과거 초과매도 거절·정확한 십진 원장·기기 저장 | 코어와 App의 AsyncStorage 저장 경로를 따로 검증 |
| 회원 | 조회·거래 등록·이력·알려진 종목 거래 수정·거래 삭제 | 외부 Google/네이티브 쿠키는 기기 검증 필요 |
| 평가 | 서버 calculate·평가금액·손익·회원 추이·게스트/회원 분석 | 외부 AI 제공자 실행과 로컬 데이터 결과 구분 |
| 뉴스/탐색 | 카테고리/페이지·상세·키워드·시장 분석·뉴스/콘텐츠 검색·종목 자료·인물 | 정밀 차트/영상 임베드 대신 웹 출처 링크 |
| 일정 | 월 이동·전체/내 종목·게스트/회원 일정 | 모바일 실제 화면 동작 추가 필요 |
| 계정 | 외부 브라우저 PKCE·프로필·닉네임·로그아웃·탈퇴·피드백 | Google 실계정 인증과 OS 쿠키 수명 미검증 |
| 관리자 | 뉴스 기본 편집/상태·피드백 처리, 인물/후보 읽기 | 세부 범위는 실행 기록 참고 |

미포함/남은 항목: 보유량 직접 조정·삭제 UI, 게스트 opening/adjustment 원장,
게스트 자산 추이, 회원 분석 자동 폴링/이력 전용 UI, 관리자 이미지 업로드·이미지 생성·
인물/게시물/후보 큐 쓰기·종목 콘텐츠 관리·동기화 UI, 소개/정책 문구·투어와 정밀 화면 재현.
API route 등록만으로 해당 기능의 화면 구현/실제 통과를 주장하지 않는다.

쓰기401은 기존 Flutter 모바일 안전 정책을 따라 자동 재전송하지 않는다.
원본 웹의 쓰기1회 재전송과 차이가 있으므로 실패 이후 사용자가 조회로 결과를 확인한다.
원본·Rust 서버·다른 클라이언트는 수정하지 않는다.

현재 Rust의 뉴스 category query는 STOCK/ETF/REAL_ESTATE만 받으므로 화면 필터는 이 세개와 전체만 노출한다.
응답 디코더는 원본의10개 category를 보존한다. 경제/채권/금/외환 등의 필터 확장은 백엔드 지원이 남았다.
