# Flutter 앱 화면 기준

전체 사용자 앱의 기본 탐색은 검색·포트폴리오·뉴스·캘린더·내 정보 5개다.
작은 화면에서는 하단 NavigationBar, 넓은 화면에서는 NavigationRail을 사용한다.
첫 화면은 검색이며, 임의 시세·가짜 수익률·가짜 회원 정보를 정상 데이터처럼 표시하지 않는다.

지식베이스의 입력·상태·접근성 계약과 ui-ux-pro-max의 Flutter/모바일 규칙을 적용한다.
디자인 시스템 검색은 투자/금융에도 랜딩페이지 패턴과 맞지 않는 글꼴을 반환했다.
이 결과를 제품 화면의 기준으로 채택하지 않고 아래 앱에 맞는 판단을 사용한다.

- 금융 유틸리티에 맞춰 시스템 한국어 sans-serif, 명확한 숫자, 여유 있는 8px 간격을 사용한다.
- 밝은 회색 바탕과 청색 주요 동작, 같은 구조의 어두운 테마를 제공한다.
- 실시간과 최근 저장 종가를 구분하고 통화·거래일을 금액 옆에 표시한다.
- 통계는 서버 계산을 표시하며 가격 없음·부분 계산·빈 보유를 별도 상태로 보여준다.
- 모든 탭에 로딩·빈 결과·오류·재시도를 제공한다. 실패를 빈 목록으로 감추지 않는다.
- 검색은 국가/유형을 분리한다. 유형은 받은 검색 결과의 로컬 필터다.
- 회원 작업은 로그인 상태에서만 가능하고, 공개 계산용 게스트 초안과 서버 원장을 구분한다.
- 거래 쓰기는 자동 재시도하지 않는다. 결과가 불확실하면 목록 재조회로 확인하게 안내한다.
- 닉네임·거래 입력·피드백에 보이는 label과 필드 오류를 둔다.
- 터치 영역 최소48dp, SafeArea, 키보드 스크롤, 좁은 화면과 큰 글자 크기를 고려한다.
- 스크린리더의 상태/오류 안내, 아이콘 tooltip, 색상 외 손익 부호/문구를 제공한다.
- 뉴스/분석의 외부 링크는 HTTP/HTTPS 출처만 열며 데이터 문자열을 HTML로 실행하지 않는다.

검증 담당은 좁은/넓은 화면, 밝은/어두운 테마, 큰 글씨·탐색·입력·오류를 실제 위젯이나
브라우저로 확인하고 미확인 디바이스 항목을 구분해서 기록한다.
