# iOS pilot contract — test-author boundary

Baseline iOS 17+, Swift 6 language mode, host Swift 6.3.3/macOS Foundation. Xcode/iOS SDK absent; no device success claim. `Contracts.swift` is authoritative for public value types/protocols. No external dependencies.

Implementation files to hand off after compiling red run:
- `API.swift`: `public struct StockAPI: MarketAPI` with `public init(baseURL: URL, transport: any HTTPTransport)`, `public func search(keyword: String, country: Country = .KR) async throws -> [Stock]`, `public func latestPrice(assetId: Int64) async throws -> Quote`.
- `MarketModel.swift`: `@MainActor public final class MarketModel`, `public private(set) var state: MarketState`; `public init(api: any MarketAPI, debounce: @escaping @Sendable () async throws -> Void = { try await Task.sleep(for: .milliseconds(250)) })`; synchronous public methods `updateQuery(_ value: String)`, `updateCountry(_ value: Country)`, `select(_ stock: Stock)`, `editPrice(_ value: String)`, `changeStock()`, `deactivate()`, `activate()`, `retrySearch()`, `retryPrice()`, `restore(snapshot: MarketDraft)` and `snapshot() -> MarketDraft`. `updateFilter(_ value: CategoryFilter)` and read-only `filteredResults: [Stock]` preserve full results while filtering locally. Implementation may add @Observable to the @MainActor model for native SwiftUI observation without changing these signatures.

`state.draft` contains query, country, selected, unitPrice, priceEdited, filter. `state.search/price` use LoadState idle/loading/ready/failed. API returns normalized `currency` KRW/USD (missing or null uses code .US fallback). Explicit unsupported or nonstring currency uses the same code fallback: deliberate defensive mapping matching approved Android policy; original web does not validate it and nullish fallback alone can return malformed currency. Exact numeric token spelling is retained as Quote.closePrice String: no arithmetic/rounding or Double conversion. All JSON numeric precision, including more than Decimal's ~38 significant digits, can be held in this string; arithmetic is outside pilot. Reject nonnumeric JSON prices, booleans, nonfinite overflowing numeric values; dates remain strings even if invalid calendar spelling, matching original decoder.

Original evidence: `reference/2026-DAYNOMY-dev/frontend/src/features/stocks/api.ts` searchStocks/isStock/getLatestStockPrice for URL encoding, safe integer IDs, market/category and price/date types; `types.ts` stockCurrency fallback; `PortfolioTransactionEditor.tsx` effects and change('unitPrice') for 250 ms debounce, JavaScript trim (BOM removed; NEL preserved), cancellation, dirty deletion, positive-only price auto-fill and stock-change reset. Malformed currency fallback is additional native defensive policy. Lexical precision is native preservation policy: web converts price to JS Number and loses that precision.

State lifecycle native policy: deactivate cancels/invalidate requests, sets both loads idle and keeps draft; activate reissues search/price as appropriate, preserving dirty input. changeStock clears selection, price/dirty, quote state; resumes query search. country change clears results and updates query generation. restore invalidates old tasks, copies only draft and reissues applicable work when active. Back navigation calls deactivate; no persistent authentication/storage. Late success, failure, and finally/loading work must not mutate a newer generation. Cancelled operations remain non-error. Retry may be updateQuery(current query).

HTTP classification: 404 + JSON code STOCK_PRICE_NOT_FOUND -> notFound; other 404 -> http(404), 401 -> unauthorized, other non-2xx -> http(status); malformed successful data -> invalidResponse; transport failures -> network; CancellationError and URLError.cancelled -> cancelled. No auth refresh in public pilot.
