# iOS 공통 UI 적용 — Issue #31

사용자 요청(2026-11-04): 기존 iOS에 공통 UIUX를 적용한다. 선행 PR #30의 상태 수정과 기존 API/원장 계약을 유지한다.
공통 결정은 Android 작업의 [spec/uiux.md](https://github.com/choiyoung69/daynomy_agent/blob/b1b7ded7/spec/uiux.md) 2·11·12절과 실제 Android 캡처를 재사용했다. 새 시안·제품 데이터를 생성하지 않는다.

- 첫 목적지는 포트폴리오, 하단은 포트폴리오·이슈·내 계정 세 목적지다. 전역 고정 검색창이나 독립 종목 탭을 두지 않는다. 종목 조회는 포트폴리오의 맥락 진입으로 기존 종목 검색·종가 조회와 USD 거래의 환율 입력을 유지한다.
- 흰 표면(어두운 모드에서는 시스템 배경), 주요 텍스트·검정 주요 동작, 청색 선택, 평면 구분선과 20pt 중심 여백을 사용한다. SF Symbols·시스템 글자·Dynamic Type·기본 뒤로 가기/시트/44pt 조작을 유지한다.
- 포트폴리오는 실제 평가 요약과 확인 전/오류/빈 보유를 구분하고 금액 숨김을 화면 텍스트·접근성에도 적용한다. 보유 자산/거래 내역을 전환하며 거래 추가/수정/삭제·보유 정정과 기존 보조 기능을 유지한다. 전량 매도와 거래 없음은 다르며 누적 실현손익을 숨기지 않는다.
- 오늘 뉴스는 서버 `/api/news/today` 응답 발행순 최대9건을 사진+어두운 scrim+제목/분류/날짜로 표시한다. 상대 이미지 URL은 실제 API 설정 기준으로 해석하고 이미지 로딩/없음/실패를 구분한다. 좌우 이동 및 44pt 이전/다음, 현재 위치를 제공하고 자동 넘김은 하지 않는다. 상세 왕복 후 선택 기사를 유지한다.
- 검색 초안과 제출된 검색어를 분리한다. 키보드 Search/Enter에서 `/api/search/news`를 호출한다. 정렬/분야/페이지/해제와 늦은 응답 무효화를 유지한다. 오늘 뉴스와 검색 결과의 실패·빈 결과는 독립 상태다.
- AI 포트폴리오 분석은 요약 근처에서 직접 진입한다. 기존 분석 UI와 상태/API를 재사용하되 단독 진입에서는 캘린더 UI·요청을 실행하지 않는다. 캘린더 보조 진입은 유지하고 AI 생성은 기존 명시적 버튼에서만 실행한다.
- 계정은 실제 로그인·프로필·닉네임·로그아웃·탈퇴를 유지하고 의견 보내기는 별도 입력 시트로 연결한다. 오류일 때만 계정 복구 조회를 제공한다. 없는 회원 정보나 설정 메뉴를 추가하지 않는다.
- Android에 한정된 콘텐츠/캘린더/관리자 제외 결정을 iOS 기능 삭제로 적용하지 않는다. iOS 기존 기능은 보조 진입을 유지한다. 리그·F14·배포 보류도 유지한다.

기존 UI 기준은 보존하고 새 탐색 계약의 명시적 개정 인수를 `experiments/ios-common-ui/test-author/`에 둔다. 합성 HTTP UI/정적 검사/실제 SDK 빌드/실제 제공자·Rust/DB 검증은 구분한다. 실제 검사·캡처·독립 리뷰 및 미검증은 `experiments/ios-common-ui/README.md`와 PR에 연결한다.
