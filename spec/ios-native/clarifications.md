# 원본 대조 후 보완

2026-10-28. 최초 고정 계약·테스트는 변경하지 않는다. 아래는 독립 원본 대조와 실제 HTTP가
발견한 경계 및 수정 근거이며, 최초 22개 테스트의 충분성을 주장하지 않는다.

- `URLSearchParams`의 폼 쿼리에서 문자 `+`는 `%2B`로 전달해야 한다. Foundation의
  `URLComponents.queryItems`는 `+`를 그대로 둘 수 있어 실제 폼 디코더에서 공백으로 바뀌었다.
  실제 루프백 HTTP에서 실패를 확인했고, 별도 작성자가 정확한 수정 전 소스에 회귀 검사를 추가한다.
- JSON 숫자의 편집용 원문은 그대로 보존한다. UI의 자동 채움 가능 여부는 원본처럼
  유한한 Double 값이 0보다 큰지 확인한다. `1e-400`은 디코더가 원문을 읽어도
  원본 JS Number에서 0으로 내려가므로 UI 자동 채움은 거절한다. 표시 문자열을 Double로 재생성하지 않는다.
- 응답 JSON의 중복 키는 원본 `JSON.parse`처럼 마지막 값을 사용한다. 최초 구현에 있던
  불필요한 중복 키 거절을 제거했다. 깊이 제한은 비정상 응답의 자원 보호 경계다.
- `0.` 뒤에 많은 0과 1이 있는 숫자에 지수를 붙여 정확히 1이 되는 ID도 값 기준으로 읽는다.
  소수부의 선행 0을 정규화한 뒤 정수성과 안전 정수 범위를 검사한다.
- 시장 필드는 허용 문자열 enum만 읽고, 잘못된 통화는 코드 기반 KRW/USD로 정규화한다.
  이는 기존 Android와 같은 명시적 네이티브 방어 매핑이며 원본의 강제 변환·미검사를 그대로 복제한 것은 아니다.

기준: 원본 `frontend/src/features/stocks/api.ts`, `types.ts`,
`PortfolioTransactionEditor.tsx` 및 `app/src/api.rs`의 폼 쿼리 처리.
해시와 실행 로그는 `experiments/ios-native/`의 독립 검증·추가 테스트 기록을 따른다.
