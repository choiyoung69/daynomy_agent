# Android 포트폴리오 — 공통 웹 디자인 첫 적용

Issue #15. 2026-11-04 사용자 결정: 기존 웹 디자인을 공통 기준으로 확정하고 Android 포트폴리오부터 적용한다.
공통 근거·토큰·반응형 전환은 [원본 웹 UI 기준](../../docs/design/2026-11-04-web-reference/README.md)을 따른다.

- 요약 → 보유 자산/거래 내역 → 접힌 자산 분석 → 관련 소식의 순서를 유지한다. 거래 입력은 명시적으로 열고 닫는 별도 화면이며 시스템 뒤로 가기를 지원한다.
- 웹의 흰 표면·검정 주요 행동·청색 강조·구분선·pill 버튼을 Compose 토큰으로 사용한다. 사용자 후속 결정에 따라 하단 3탭(포트폴리오/이슈/내 계정)을 유지하고 전역 검색은 제거한다. 종목 검색은 거래 입력과 종목 조회 안에 제공하고, 환율은 미국 종목/거래 맥락에서 연다.
- 최소 48dp 터치 영역·플랫폼 한국어 글꼴·스크롤·IME·접근성 이름/상태를 적용한다. 웹 DOM·정확한 픽셀 크기·리그 메뉴를 그대로 복사하지 않는다.
- Android에 없는 게스트 자산 임시 저장·보유 종목 뉴스는 활성 기능으로 표시하지 않는다. 회원 AI 분석은 별도 계약에 따라 실제 API에 연결한다. 로그인 필요 상태에서는 실제 계정 화면으로 이동한다.
- 평가 전은 평가 조회 필요로 표시한다. 첫 로딩/조회 실패/로그인 필요에는 미확인 요약·보유 목록을 숨기고 해당 안내를 표시한다. 확인된 빈 보유만 0원을 표시한다. 부분 평가의 null 금액과 기준일 혼합을 구분하며 수치/비중은 기존 서버 응답에서 표시한다.
- 새로 조회할 때 이전 평가·수익률을 무효화한다. 조회 실패를 빈 성공으로 바꾸지 않는다. 인증 실패 때 이전 회원의 보유/이력/요약을 지운다.
- 거래 단가·수량·비용·환율의 원문 입력과 기존 HTTP/CSRF 경계를 유지한다. 저장 결과 불명은 자동 재전송하지 않으며, 내역 재조회로 확인한다.
- 보유 조정·제거·거래 수정·삭제·기간 수익률·평가는 기존 기능을 유지한다. 수익률 그래프 시각화는 준비 중임을 표시하고 실제 저장 수익률의 텍스트 조회를 제공한다.
- 종목 조회/거래 입력 검색은 기존 F03이며 이슈 Search API와 분리한다. 검색 결과에서 종목을 선택한 뒤 새 검색어를 입력하면 선택/가격 초안을 초기화한다.
- 기존 세션/원장 API는 변경하지 않는다. 원본 서버·DB 또는 다른 클라이언트는 이 UI 적용을 위해 실행하지 않는다.

회전/Activity 재생성·가로·글자 확대와 입력 열기/취소·조회 실패/로그인 필요/부분 평가·거래 결과 불명을 네이티브 인수 검사로 확인한다.
실제 실행 결과와 남은 검증은 [실험 4의 Android 적용 기록](../../docs/time-token-experiment.md#android-적용--issue-15)에 둔다.

## 승인 시안의 Compose 적용

사용자가 승인한 [이미지 시안](../../docs/design/2026-11-04-web-reference/concepts/portfolio-v1.png)을 실제 Compose 입력·버튼·탭·목록으로 구현한다. 이미지는 앱 자산으로 사용하지 않는다. 평가액·부호 있는 손익/수익률·매입금액·기준일은 기존 HTTP 응답에 연결한다. 미확인/부분 평가의 값은 대체 숫자를 만들지 않는다. 최초 평가는 기존 명시적 조회 동작을 유지한다.

보유 관리 메뉴와 접힌 평가/수익률 상세에서 기존 기능을 제공한다. 탭 전환 후 금액 숨김·입력 초안은 SaveableStateHolder로 유지한다. 재평가/수익률 조회 시 이전 결과를 무효화하며 인증 만료는 회원 데이터를 지우고 늦은 응답도 차단한다. 검색/하단 탭/관리 아이콘은 기존 Compose BOM의 material-icons-core를 사용한다.

검증 agent의 별도 인수 검사와 시각 대조 결과·현재 코드 해시는 [검증 자료](../../docs/design/2026-11-04-web-reference/android/verification.json)에 연결한다. 실기기 TalkBack·실제 서버/OAuth는 이번 검증에 포함하지 않았다.

## 추가 개발 범위

2026-11-04 사용자 결정에 따라 추가 기능은 기존 백엔드 F06의 AI 포트폴리오 분석까지만 포함한다. 현재 평가/수익률 상세는 AI 분석이 아니며 [Android 회원 AI API/화면](ai-analysis.md)을 연결했으며 실제 외부 AI 호출은 미검증이다. 투자 캘린더·통합 콘텐츠/인물·관리자 화면은 Android 개발 대상에서 제외한다. 공통3탭은 유지하며 백엔드 API는 삭제하지 않는다.
