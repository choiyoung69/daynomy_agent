# Android 포트폴리오 — 공통 웹 디자인 첫 적용

Issue #15. 2026-11-04 사용자 결정: 기존 웹 디자인을 공통 기준으로 확정하고 Android 포트폴리오부터 적용한다.
공통 근거·토큰·반응형 전환은 [원본 웹 UI 기준](../../docs/design/2026-11-04-web-reference/README.md)을 따른다.

- 요약 → 자산 분석 → 보유 자산/거래 내역 → 관련 소식의 순서를 유지한다. 거래 입력은 명시적으로 열고 닫는 별도 화면이며 시스템 뒤로 가기를 지원한다.
- 웹의 흰 표면·검정 주요 행동·청색 강조·구분선·pill 버튼을 Compose 토큰으로 사용한다. 기존 앱 탐색은 유지하고, 포트폴리오가 선택됐을 때 탐색 칩도 같은 색을 적용한다.
- 최소 48dp 터치 영역·플랫폼 한국어 글꼴·스크롤·IME·접근성 이름/상태를 적용한다. 웹 DOM·정확한 픽셀 크기·리그 메뉴를 그대로 복사하지 않는다.
- Android에 없는 게스트 자산 임시 저장·AI·보유 종목 뉴스는 활성 기능으로 표시하지 않는다. 로그인 필요 상태에서는 실제 계정 화면으로 이동한다.
- 조회 전/실패/로그인 필요의 요약 금액은 `—`다. 확인된 빈 보유만 0원을 표시한다. 부분 평가의 null 금액과 기준일 혼합을 구분하며 수치/비중은 기존 서버 응답에서 표시한다.
- 새로 조회할 때 이전 평가·수익률을 무효화한다. 조회 실패를 빈 성공으로 바꾸지 않는다. 인증 실패 때 이전 회원의 보유/이력/요약을 지운다.
- 거래 단가·수량·비용·환율의 원문 입력과 기존 HTTP/CSRF 경계를 유지한다. 저장 결과 불명은 자동 재전송하지 않으며, 내역 재조회로 확인한다.
- 보유 조정·제거·거래 수정·삭제·기간 수익률·평가는 기존 기능을 유지한다. 수익률 그래프 시각화는 준비 중임을 표시하고 실제 저장 수익률의 텍스트 조회를 제공한다.
- 기존 세션/원장 API는 변경하지 않는다. 원본 서버·DB 또는 다른 클라이언트는 이 UI 적용을 위해 실행하지 않는다.

회전/Activity 재생성·가로·글자 확대와 입력 열기/취소·조회 실패/로그인 필요/부분 평가·거래 결과 불명을 네이티브 인수 검사로 확인한다.
실제 실행 결과와 남은 검증은 [실험 4의 Android 적용 기록](../../docs/time-token-experiment.md#android-적용--issue-15)에 둔다.
