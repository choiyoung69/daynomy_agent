# 기존 Rust 기능에 대응하는 Android 구현 범위

기준은 spec/service.md와 runs/010-three-hour-service.md다. 리그·F14이메일·운영 배포는 제외한다.
수집/배치는 Rust에 둔다. 아래 표는 백엔드 기능 대응 현황이며 Android의 필수 개발 목록이 아니다.

2026-11-04 최신 사용자 결정: Android는 현재 포트폴리오·이슈·내 계정과 종목/거래/환율/피드백 흐름에 **AI 포트폴리오 분석까지만** 포함한다. 투자 캘린더·통합 콘텐츠 검색·콘텐츠/인물·관리자/수집 관리 화면은 개발 대상에서 제외하고 메뉴를 추가하지 않는다. 기존 백엔드 기능/API는 삭제하지 않는다.

AI 분석은 기존 회원 백엔드 계약에 [Android API/화면](ai-analysis.md)을 연결했다. 기존 평가/수익률 숫자 화면과 구분한다. 실제 외부 AI/DB 호출은 이번 검증에 포함하지 않았다.

| 영역 | Android 구현 | 검증 범위 |
|---|---|---|
| F01 인증 | 외부 브라우저 PKCE·콜백·CSRF·메모리 쿠키·갱신·로그아웃 | JVM+합성 코드 실제 Rust; 실제 Google 계정 별도 |
| F02 회원 | 내 정보·닉네임·탈퇴 화면/클라이언트 | 프로필/닉네임 실제 Rust; 탈퇴 전체 인수 별도 |
| F03 종목/가격/환율 | 국내/미국 검색·종가·날짜별 환율 | 기존 JVM·실제 Rust/DB·기기 |
| F04 평가 계산 | 보유자산 평가 클라이언트·화면 | 실제 Rust 계산; 화면 버튼 전체 별도 |
| F05 내 자산/거래 | 보유자산·매수/매도·수정/삭제·이력·조정·성과 화면/클라이언트 | 실제 Rust 거래 원장과 불확실 전송 화면; 모든 조합 인수 아님 |
| F06 AI | 회원 저장 분석·명시 생성/근거 갱신·부분/이전 결과·출처·이력 [연결](ai-analysis.md) | JVM 계약/상태·합성 HTTP 네이티브 검증. 실제 외부 AI/DB/OAuth·게스트/V2 UI는 이번 범위 아님 |
| F07 투자 캘린더 | Android 개발 대상 제외 | 완료 조건에 포함하지 않음 |
| F08 뉴스 | 목록·분류·페이지·상세 본문·출처·[오늘 뉴스](today-news.md) | 이슈 상단 대시보드와 실제 검색을 독립 조회. 이번 검사 결과/코드 해시는 디자인 검증 자료·실험4에 기록. 실제 오늘 Rust/DB·자정 경계 미검증; 상단 캐러셀 이미지 조회 구현; 목록/상세 이미지 확장·키워드/시장분석 남음 |
| F09 검색 | [뉴스 Search API](news-search.md)·명시 제출/해제·분류/정렬/페이지/상세 복귀 | Issue #11 구현 재사용·Issue #15 UI 통합. 통합 콘텐츠 검색은 Android 개발 대상 제외; 이번 실제 서버/DB 의미 검증 미실행 |
| F10 콘텐츠/인물 | Android 개발 대상 제외 | 완료 조건에 포함하지 않음 |
| F11 피드백 | 구현·검증 범위는 [실행 기록](../../runs/024-android-feedback.md) 참조 | [계약](feedback.md), 입력·공개 CSRF 전송·중복 방지·결과 불명 처리 |
| F12 관리자 | Android 개발 대상 제외 | 완료 조건에 포함하지 않음 |
| F13 수집·배치 | 기존 Rust 기능 유지, Android 관리 화면 개발 대상 제외 | 백엔드 유지와 앱 범위는 별개 |

단계별 실제 증거·미완료는 runs/014·015·017, experiments/android-native/core30의 별도 검증 결과를 따른다.
서버 기능 구현, Android 클라이언트 구현, 실제 검증 완료를 서로 바꾸어 표시하지 않는다.
